## 🚀 À propos

**Gymbro** est une application complète pour les passionnés de fitness et de musculation. Que tu sois débutant ou athlète confirmé, Gymbro t'accompagne dans chaque séance.

### ✨ Fonctionnalités principales

- **🏋️ Modes d'entraînement variés** — Classic, Timed, Circuit, Tabata, EMOM, AMRAP, For Time
- **📊 Suivi de progression** — Historique complet, graphiques d'évolution, PRs
- **📱 Live Activity iOS** — Widget dynamique pendant tes séances
- **👨‍🏫 Plateforme Coaching** — Trouve un coach ou deviens coach
- **🌍 Feed Social** — Partage tes workouts et suis tes amis
- **📚 Bibliothèque d'exercices** — +500 exercices avec instructions
